# Supply-Chain-Analysis-Capstone
Supply Chain Performance Analytics using Python, Pandas, NumPy and Power BI


## 📌 Project Overview

The **Supply Chain Analysis Capstone** is a Data Analytics project focused on analyzing product sales, manufacturing, inventory, quality, and logistics data.

The objective of this project is to extract meaningful insights and actionable recommendations from supply chain data to help optimize operations and improve profitability.

The project uses **Python/Jupyter Notebook** for data cleaning and analysis and **Power BI** for interactive dashboard development.

---

## 🎯 Problem Statement

The supply chain dataset contains information related to:

- Product sales
- Manufacturing
- Inventory
- Product quality
- Shipping
- Transportation
- Routes
- Shipping carriers

The goal is to analyze this information and identify patterns and business insights that can support better supply chain decisions.

---

## 🎯 Project Objectives

The main objectives of this project are:

- Analyze the number of products sold and revenue generated.
- Understand sales performance by product type.
- Analyze customer demographics.
- Track product availability and stock levels.
- Analyze manufacturing lead times and costs.
- Analyze order quantities and production volumes.
- Monitor inspection results and defect rates.
- Analyze shipping costs.
- Compare transportation modes and routes.
- Analyze shipping times and shipping carriers.
- Identify areas for operational and cost improvement.
